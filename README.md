# Farnova Brands — E-Commerce Website

A modern e-commerce product showcase website designed for Farnova Brands.

## About the Project

Farnova Brands showcases perfumes, lighting products, and other merchandise through a premium, user-friendly interface.

## Features

- Modern, responsive website design
- Interactive 3D Perfume Cards Cascade
- Product catalog with images, prices, and descriptions
- WhatsApp ordering integration
- Firebase Firestore database
- Product management dashboard
- Role-based administrator access controls

## Technologies and Tools

- Google AI Studio
- Firebase Firestore
- Modern frontend web technologies
